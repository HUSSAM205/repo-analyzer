# Public Access & Gemini Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the login wall by adding an invisible, auto-provisioned guest identity; make analyzed repos/conversations publicly readable by anyone with the link; dedupe repeat analyses of the same URL globally; extend rate limiting to chat; and add Google Gemini as a real third LLM provider.

**Architecture:** Every change is additive or relaxing, not a rewrite — the existing JWT + token-bucket-rate-limiter + SQLAlchemy/Alembic infrastructure stays exactly as it is; guests are just `User` rows with `is_guest=True` and no password, ownership checks are removed (not replaced) on read paths, and `GeminiClient` is a fourth implementation of the existing `LLMClient` protocol sitting next to `AnthropicClient`/`OpenAIClient`.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 async, Alembic, PostgreSQL, Redis, `google-genai` (new dependency), pytest + pytest-asyncio + httpx `AsyncClient`.

**Spec:** `docs/superpowers/specs/2026-08-17-public-access-gemini-design.md`

## Global Constraints

- No CAPTCHA, IP-based throttling, or abuse defense beyond the existing per-identity Redis token bucket, now also guarding chat.
- No data retention/expiration policy for guest-created data — it persists exactly like registered-user data.
- The existing registered-user auth endpoints (`/auth/register`, `/auth/login`, `/auth/api-keys`) are NOT removed or modified — they keep working, in the backend and in every existing automated test that exercises them.
- No production data-migration story needed for the `repos` table uniqueness-key change — this project has no production data yet.
- `GET /api/v1/repos` (the list endpoint) is the one endpoint that does NOT become public — it stays scoped to `Repo.user_id == current_user.id`.
- Every other read endpoint drops its ownership check but keeps requiring *a* valid bearer token (guest or real) — `current_user` stays a required FastAPI dependency everywhere.
- No live Gemini (or Anthropic/OpenAI) API calls in any automated test — the fake provider is the only one automated tests exercise directly; a real Gemini call is a manual, documented smoke test only.
- `gemini_model` default is `"gemini-3.7-flash"` — verified against Google's current model docs as of this plan's writing (`gemini-2.0-flash` and earlier are deprecated/shutting down). If this has changed again by the time this task is implemented, confirm the actual current default before using it.
- A real `GEMINI_API_KEY` is already present in the worktree's gitignored `backend/.env` — never print it, never commit it, never put it in a test file or a committed fixture.

```python
def _to_gemini_contents(messages: list[Message]) -> list[genai_types.Content]:
    # Gemini's function-calling protocol has no call id -- a function_response
    # is matched to its function_call by NAME. Build a lookup from every
    # ToolCall's id (our own bookkeeping identifier, meaningless to Gemini)
    # to its name, so a "tool" role message (which only carries a
    # tool_call_id) can be translated correctly.
    call_id_to_name: dict[str, str] = {tc.id: tc.name for msg in messages for tc in msg.tool_calls}

    result: list[genai_types.Content] = []
    for msg in messages:
        if msg.role == "user":
            result.append(genai_types.Content(role="user", parts=[genai_types.Part.from_text(text=msg.content)]))
        elif msg.role == "assistant":
            parts: list[genai_types.Part] = []
            if msg.content:
                parts.append(genai_types.Part.from_text(text=msg.content))
            for tc in msg.tool_calls:
                parts.append(genai_types.Part.from_function_call(name=tc.name, args=tc.arguments))
            result.append(genai_types.Content(role="model", parts=parts))
        elif msg.role == "tool":
            name = call_id_to_name.get(msg.tool_call_id or "", "")
            result.append(genai_types.Content(
                role="tool",
                parts=[genai_types.Part.from_function_response(name=name, response={"result": msg.content})],
            ))
    return result


class GeminiClient:
    def __init__(self, api_key: str, model: str):
        self._client = genai.Client(api_key=api_key)
        self._model = model

    async def stream_chat(
        self, messages: list[Message], tools: list[ToolSpec], system_prompt: str
    ) -> AsyncIterator[LLMEvent]:
        gemini_tools = [
            genai_types.Tool(function_declarations=[
                genai_types.FunctionDeclaration(
                    name=t.name, description=t.description, parameters_json_schema=t.parameters
                )
                for t in tools
            ])
        ] if tools else []
        config = genai_types.GenerateContentConfig(system_instruction=system_prompt, tools=gemini_tools)

        try:
            content_parts: list[str] = []
            tool_calls: list[ToolCall] = []
            call_counter = 0

            stream = await self._client.aio.models.generate_content_stream(
                model=self._model,
                contents=_to_gemini_contents(messages),
                config=config,
            )
            async for chunk in stream:
                if chunk.text:
                    content_parts.append(chunk.text)
                    yield LLMEvent(type="token", token=chunk.text)
                if chunk.function_calls:
                    for fc in chunk.function_calls:
                        call_counter += 1
                        tool_calls.append(
                            ToolCall(id=f"call_{call_counter}", name=fc.name, arguments=dict(fc.args or {}))
                        )

            if tool_calls:
                yield LLMEvent(type="tool_call", tool_calls=tool_calls)
            else:
                yield LLMEvent(type="message_done", message=Message(role="assistant", content="".join(content_parts)))
        except Exception:
            logger.exception("GeminiClient.stream_chat failed (model=%s)", self._model)
            yield LLMEvent(type="error", error=_PROVIDER_ERROR_MESSAGE)
```
